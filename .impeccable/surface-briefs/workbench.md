# Git workbench

Mode: Operate. Platform: Windows desktop with a web-rendered interface.
User-approved scope and architecture are recorded in PRODUCT.md.

## Direction contract

THESIS: Git state is the interface: changed paths, index, commit ancestry, refs, and interrupted operations remain visible without dashboard summaries.

OWN-WORLD: Mac-inspired precision with Windows behavior. Segoe UI Variable, neutral frame and white sheet, compact controls, blue selection, semantic additions/deletions, native titlebar. Dark mode preserves the same topology.

STORY: Open a repository, inspect its state, trust its executable configuration deliberately, review a precise diff, stage a coherent change, commit and synchronize.

FIRST VIEWPORT: A 208px labeled repository sidebar and 52px toolbar wrap an inset sheet. Repository tabs lead into a 320px changes pane and a full-height diff. The commit form is anchored below the file list; terminal and operation log share a bottom drawer.

FORM: Framed sheet from design-taste-frontend, seed 1266066839. Palette and typography pinned by the user's plan. Signature interaction: file selection reveals its index/worktree comparison immediately. Keyboard actions do not animate. seed: none (unavailable).

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
