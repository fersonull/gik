# Git workbench

Mode: Operate. Platform: Windows desktop with a web-rendered interface.
User-approved scope and architecture are recorded in PRODUCT.md.

## Direction contract

THESIS: Git state is the interface: changed paths, index, commit ancestry, refs, and interrupted operations remain visible without dashboard summaries.

OWN-WORLD: Mac-inspired precision with Windows behavior. Locally bundled Inter Variable on Windows, Apple system faces on macOS, neutral frame and white sheet, compact controls, blue selection, semantic additions/deletions, and integrated themeable Windows caption controls. Dark mode preserves the same topology. A separate five-color graph palette follows branch continuity.

STORY: Open a repository, inspect its state, trust its executable configuration deliberately, review a precise diff, stage a coherent change, commit and synchronize.

FIRST VIEWPORT: A 208px labeled repository sidebar and 52px toolbar wrap an inset sheet. The toolbar integrates dragging and Windows window actions; F11 hides it entirely. Repository tabs lead into a 320px changes pane and a full-height diff. History starts with a 560px list pane. Both splits resize by pointer or keyboard and persist independently. The commit form is anchored below the file list; terminal and operation log share a bottom drawer. The branch control opens a searchable popover, and occasional forms use roomier dialogs within the compact workbench.

FORM: Framed sheet from design-taste-frontend, seed 1266066839. Palette and typography follow the user's approved refinements. Signature interaction: file selection reveals its index/worktree comparison immediately. Purposeful motion is on by default for pointer-driven occasional surfaces, with a persistent Settings switch and reduced-motion override. Keyboard navigation and data surfaces stay immediate. No raster illustrations.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
