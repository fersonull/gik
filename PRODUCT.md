# Gik

<!-- impeccable:product-schema 1 -->

## Platform

web

Desktop application on Windows 11 x64; later macOS and Linux. Integrated, theme-aware caption controls with native Windows window actions and shortcuts. F11 fullscreen hides the chrome.

## Stack

Delegated and confirmed: Tauri 2, Rust, React, TypeScript, Vite; installed Git; xterm.js and native PTY.

## Users

Experienced developers managing local Windows Git repositories throughout the workday.

## Product Purpose

Inspect, change, synchronize, and recover repositories through precise visual workflows, with terminal access to every installed Git command.

## Capabilities and Constraints

Broad Git workbench: changes, history, branches, tags, stashes, worktrees, remotes, recovery, conflicts, and history editing. Installed Git owns repository state. No hosting accounts, telemetry, WSL, or network-share support in v1. Never promise recovery of discarded uncommitted content.

## Brand Commitments

Working name Gik. macOS-inspired craft with Windows-native behavior. Light and dark themes, following the OS by default. Mac-like Inter Variable typography. Rich, purposeful motion enabled by default with a persistent performance switch and reduced-motion support. Compact neutral panels and color reserved for meaningful state.

## Product Principles

- Git is the source of truth.
- Make repeated actions immediate and keyboard accessible.
- Preview destructive actions and reject stale previews.
- Trust repository tools only with explicit consent.

## Accessibility & Inclusion

Keyboard navigation, screen reader semantics, visible focus, high contrast, reduced motion, text scaling, and non-color state indicators.
